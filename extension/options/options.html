Connect Hermes Brief to your Hermes

The extension talks only to your own Hermes Agent on this computer. Nothing goes anywhere else.

Hermes's API server address. The default is http://127.0.0.1:8642.

If you run several profiles on one gateway, the one Hermes Brief is enabled in. Leave empty for the default profile.

The API_SERVER_KEY from your Hermes .env. Stored only in this browser.

Bookmark anything into this Chrome folder (or a subfolder) and it is saved. Subfolder names become Brief folders.
