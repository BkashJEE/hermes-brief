Connect Hermes Brief

The extension talks only to your own Hermes on this computer. Nothing goes anywhere else.

1. Get a code

In Hermes Desktop open Briefs and click Connect Chrome. You'll see a 6-digit code (it works for 5 minutes).

2. Enter it here
Settings

Your Hermes API server. The default is http://127.0.0.1:8642 (it must be on: API_SERVER_ENABLED=true).

Bookmark anything into this Chrome folder (or a subfolder) and it is saved. Subfolder names become Brief folders.
